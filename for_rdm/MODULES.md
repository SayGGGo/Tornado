| Модуль              | Описание                    | Основной функционал                                                                                                                         |
|:--------------------|:----------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| **`Application ✅`** | Точка входа в приложение    | Запуск сервера, инициализация Flask инстанса, подключение логгера и связывание всех модулей.                                                |
| **`Config ✅`**      | Файл конфигурации           | Чтение переменных из `.env`, настройки `SQLALCHEMY_DATABASE_URI`, ключи `SECRET_KEY`, `TURNSTILE_SECRET` и параметры Telegram.              |
| **`DB Models ✅`**   | Схемы базы данных           | Описание моделей `User`, `Message`, `UserReport` через SQLAlchemy, настройка связей между таблицами.                                        |
| **`Auth ✅`**        | Система авторизации         | Логика эндпоинтов `/login`, `/api/register`, `/logout`. Хэширование паролей, проверка капчи Turnstile, управление Flask сессиями.           |
| **`Chat ✅`**        | Логика мессенджера          | Эндпоинты `/chat` и API `/api/messages`. Защита от XSS (`markupsafe.escape`), шифрование RSA+AES, репорты `/api/report`.                    |
| **`Moderation ✅`**  | Система модерации           | Автоматические репорты по матам (уровни угрозы 1–3), список исключений, дефаз пробелов и замены букв, блокировка Anti-67.                   |
| **`Admin ✅`**       | Панель администратора       | Управление пользователями (подробная инфо, бан), репорты с контекстом 5 сообщений, Anti-67, статистика, .env редактор, управление админами. |
| **`Telegram ✅`**    | Интеграция с TG             | Изолированная работа с `Telethon`. Полноценное внедрение интеграции чатов из Telegram в Tornado.                                            |
| **`Utils ✅`**       | Вспомогательные инструменты | `get_randomization`, парсинг расписания групп (`get_groups`), проверка лицензионного ключа, фильтр мата (`profanity.py`).                   |
| **`System ✅`**      | Системные эндпоинты         | Системные маршруты                                                                                                                          |
